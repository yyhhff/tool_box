## 六、风险提示

1. **补齐不等于纯前端改动**：P1/P2 多数涉及**数据字段**（资产负债率、经营现金流、换手率、YTD、散户净流入、日程事件等），必须重走「原始数据采集 → 改 CSV 契约 → 重导在线数据表（6 个 databaseId）→ 改 HTML → 四处同步（CSV/JSON/HTML/资料库）」完整链路，并重新执行 QA 验收，不能只在 HTML 端补字段。

3. **数据时点回退风险**：对标数据截至 2026-09-01，我方 2026-11-18。若照搬对标快照字段而不更新到我方时点，会导致数据新鲜度倒退，丧失现有优势。
4. **零外部依赖权衡**：D3 若走 CDN 会破坏我方「单文件全内联、离线可用」的核心优势（QA 条目21/22）；若内联则显著增大文件体积，需评估。
5. **样本与双增口径不可简单对齐**：我方 67 家正式榜 + 95 家双增池，对标 71 家样本 + 约 49 家双增，口径不同；补齐样本数量时须保证真实来源，禁止为凑数编造（CONTRACT §4.2 不编造原则，QA 已就神华 forecastType 空值作豁免裁决）。
