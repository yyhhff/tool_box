## 1. 产品概述

### 它是什么

「2026 A股半年报分析台」是一个**打开浏览器就能用的单页分析工具**。它把 2026 年上半年（2026H1，1 月 1 日～6 月 30 日）A 股上市公司的半年报数据，按「全市场榜单 → 产业链环节 → 双增公司 → 链内公司对比 → 业绩预告 → 宏观行业对照」六个视角组织起来，让你在一个页面里就能完成从「看全貌」到「挑公司」的层层下钻。

它由 `annual_report_reader` 工具扩展而来，最终交付为**一个独立的 HTML 文件**：不需要安装软件、不需要联网账号，双击打开或访问发布链接即可使用。

### 给谁用

- 想快速了解「2026 上半年哪些公司赚钱多、哪些行业景气」的普通投资者；
- 想按产业链梳理环节利润分布、做同环节公司横向对比的研究者；
- 希望把筛选后的结果直接导出成 Excel 表格继续加工的人。

### 解决什么问题

| 痛点 | 本工具的做法 |
|---|---|
| 财报数据分散、口径不一，难以横向比较 | 统一为「营收=营业总收入、净利=归母净利润、公司 ROE=加权平均半年度未年化」的口径，并逐行标注来源 |
| 想看产业链里「哪个环节最赚钱」，但没人帮自己汇总 | 提供「产业链环节赚钱榜」，按环节自动聚合营收、净利、ROE、毛利率并给出赚钱能力排名 |
| 想找「营收和净利同时增长」的公司，筛选麻烦 | 内置「双增公司榜」，按硬条件自动入榜，并用「双增强度」排序 |
| 想在同一环节里挑几家公司并排比一比 | 「产业链内公司对比」支持勾选 2～4 家高亮并排比较，附带行情快照与技术指标摘要 |
| 担心离线打不开、数据不刷新 | 内置离线快照兜底，能连资料库时自动走在线数据，顶部徽标实时显示当前模式 |

> 说明：本工具**只陈列客观数据与文字摘要**，不提供实时行情推送、K 线图、买卖点提示或预警订阅功能。页面中出现的「最新价/涨跌幅/主力净流入/技术指标」均为某一交易日的历史快照，不是实时行情。

### 2.3 徽标含义

页面顶部的徽标会显示三种状态之一：

| 徽标文字 | 含义 | 对使用者的影响 |
|---|---|---|
| **实时资料库** | 成功连上在线资料库，六张表都读到了在线数据 | 数据为在线版本，通常最新 |
| **离线静态快照模式** | 在线资料库不可用（网络、权限或未配置），已自动回退到页面内置的静态快照 | 数据仍可正常查看和导出，但可能不是最新；免责声明旁会提示「当前为离线快照，数据可能非最新」 |
| **混合模式（部分实时 / 部分快照）** | 六张表中有的读到在线数据、有的回退了快照 | 各表独立切换，互不影响，可正常使用 |

> 打开页面时会自动尝试连接在线资料库；若失败会自动降级为离线快照，无需手动操作。重新打开或刷新页面会再次尝试连接。

### 2.4 术语小抄（先读这一栏）

| 术语 | 白话解释 |
|---|---|
| **营收 / 营业总收入** | 公司卖货和提供服务收到的全部收入（含其他业务收入）。本工具统一用「营业总收入」口径，不是窄口径的「营业收入」。 |
| **归母净利润 / 净利** | 归属于上市公司股东的净利润，也就是「真正属于母公司股东」的利润。 |
| **ROE（净资产收益率）** | 衡量「用股东的钱赚钱的效率」，数值越高一般代表赚钱效率越好。 |
| **同比** | 和去年同期（2025 上半年）相比的变化百分比。正数=增长，负数=下滑。 |
| **毛利率** | （营业收入−营业成本）÷营业收入，反映产品本身的赚钱空间。 |
| **资产负债率** | 负债合计 ÷ 资产总计，反映公司的负债水平。银行等金融业天然高负债（约 90%），需结合行业看，不是越低越好。 |
| **加权平均 ROE（未年化）** | 公司级 ROE 口径：按时间加权计算，**仅覆盖上半年、没有折算成全年**。 |
| **TTM ROE** | 行业级 ROE 口径：按最近滚动 12 个月计算。和上面的「未年化半年度 ROE」不是同一把尺子，**不能直接比较大小**。 |
| **申万一级行业** | 一种通行的 A 股行业分类（2021 版），比如「电子」「医药生物」「食品饮料」。 |
| **涨红跌绿** | A 股习惯：正数/上涨显示为红色，负数/下跌显示为绿色，0 或空值显示为灰色。 |

## 3. 界面总览

整个页面可以看成「KPI 总览卡 + 顶部筛选区 + 六个板块 + 一个弹窗」四部分。

### 3.0 顶部 KPI 总览卡

页面最上方（标题下方）有一排 7 张概览卡，让你不用翻表就能看到全局数字，数值会随数据加载自动更新：

| KPI 卡 | 含义 | 当前数值（离线快照口径） |
|---|---|---|
| **覆盖公司数** | 全市场正式半年报总榜的公司数 | 67 |
| **全市场样本** | 样本口径说明 | 2026H1 全市场 |
| **样本合计营收** | 总榜公司营业总收入之和 | 175002.22 亿元 |
| **样本合计归母净利** | 总榜公司归母净利润之和 | 21332.81 亿元 |
| **营收/净利双增公司数** | 双增榜入榜公司数 | 95 |
| **双增入榜重叠** | 双增榜与全市场总榜的**代码交集** | 8 |
| **数据时点 / 口径** | 数据整理日与统计期 | 数据时点 2026-11-18 · 2026H1 累计 |

> 关于「双增入榜重叠」：双增榜（全市场双增公司扫描，95 家）与全市场总榜（营收头部公司，67 家）是**两个不同的样本池**，两者不能直接相除算比例。这一格显示的是两个榜单共同拥有的公司家数（8 家），口径自洽、不会误导。

### 3.1 顶部全局筛选区

筛选栏里有以下控件（从左到右）：

| 控件 | 作用 |
|---|---|
| **产业链**（下拉框） | 先选一条产业链，作为所有板块的第一层过滤条件 |
| **环节**（下拉框） | 选中产业链后，这里只列出该产业链下的环节；可回到「全部环节」 |
| **板块类型**（下拉框） | 按行业/概念等类型进一步过滤（配合具体板块使用） |
| **排序维度（当前板块）**（下拉框） | 选择当前板块按哪个指标排序，每个板块的可选维度不同 |
| **关键词搜索**（输入框） | 输入代码、简称、行业、预告类型等关键词做模糊匹配，不区分大小写 |
| **升/降序切换按钮**（默认显示「降序 ⇩」） | 一键切换当前板块的升序/降序 |
| **重置筛选**（按钮） | 清空所有筛选条件，恢复到默认的「全部」视图和默认排序 |
| **导出 CSV 备份（当前板块）**（按钮） | 导出当前板块、当前筛选+排序后的结果 |
| **导出全部数据 CSV**（按钮） | 一键导出全部六张表的数据到一个 CSV 文件，按板块分段、含中文表头（UTF-8 BOM，Excel 不乱码） |
| **从在线数据表刷新**（按钮） | 在线模式下重新从资料库拉取六张表；若当前是离线快照模式，点击会提示无法刷新（不会静默失败） |
| **数据来源**（按钮） | 打开「数据来源与口径说明」弹窗 |

筛选栏标题写着：**「产业链 → 环节 → 板块类型 → 排序 → 关键词，切换后所有板块联动刷新」**——意思是任一筛选条件变化，下面六个板块会一起更新。

筛选栏下方有一条常驻**同步状态条**，与右上角的模式徽标并存，说明当前数据来自哪里：

| 状态条文案 | 含义 |
|---|---|
| ● 已连接在线数据表（实时） | 六张表全部从资料库在线读取，数据为最新 |
| ● 部分在线数据表 / 部分快照 | 部分表在线、部分表用内嵌快照兜底 |
| ● 内置快照数据（可同步在线数据表） | SDK 不可用，展示页面内嵌的离线快照（可点「从在线数据表刷新」重试） |

### 3.2 六个板块一览

| 板块 | 看什么 | 数据条数 | 默认排序 |
|---|---|---|---|
| ① 全市场正式半年报总榜 | 全部正式披露的半年报公司排名 | 67 家 | 归母净利降序 |
| ② 产业链环节赚钱榜 | 每个「产业链×环节」的利润汇总与排名 | 按环节聚合（随筛选变化） | 赚钱能力排名升序（名次靠前优先） |
| ③ 双增公司榜 | 营收、净利同比双升的公司 | 95 家 | 双增强度降序 |

| ⑥ 宏观行业对照区 | 宏观指标 + 申万行业对照 | 36 条 | 净利同比降序 |

### 3.3 数据来源弹窗

点击顶部「数据来源」按钮，弹出「数据来源与口径说明」，里面包含：

- **统一口径**：报告期 2026H1 累计（1–6 月，非单季、非年化）；营收=营业总收入；净利=归母净利润；ROE=加权平均（半年度未年化）；同比基准 2025H1（正红负绿）。
- **各表来源与时点**：一张表，逐表列出数据表名称、对应文件、当前出现的来源、数据时点、记录数。
- **说明**：来源为估算/计算值时会在备注中标注；占位数据一律写「待填」，不填 0 也不编造数字；页面底部固定免责声明，非投资建议。

## 4. 六大板块详解

每个板块都有独立的「导出当前结果」按钮，以及自己的排序维度。点击表格的**列标题**也可切换该列的升/降序。

### ① 全市场正式半年报总榜

**看什么**：截至数据时点已正式披露 2026 半年报的公司总榜，共 **67 家**。这是整个工具的「底表」，其他榜单的公司大多来自这里。

**主要字段**：

| 字段 | 含义与口径 |
|---|---|
| 股票代码 / 股票简称 | 6 位代码（保留前导零）+ 截至 2026-11-18 的简称 |
| 申万一级行业 | 申万 2021 版一级行业名 |
| 所属产业链 / 所属环节 | 公司归属的产业链标签与环节（可多标签，逗号分隔） |
| 营业总收入 | 2026H1 累计营业总收入，单位元；展示时可格式化为「亿元」 |
| 营收同比 | 较 2025H1 的变化百分比，正红负绿 |
| 归母净利润 | 归属于上市公司股东的净利润，单位元 |
| 归母净利同比 | 较 2025H1 的变化百分比，正红负绿 |
| 净利率 | 归母净利 ÷ 营业总收入 × 100，页面实时派生；缺失或分母为 0 时显示「—」。这是**水平指标，不着色**（不参与涨红跌绿） |
| 扣非净利润 | 扣除非经常性损益后的归母净利润 |
| 经营现金流净额 | 经营活动产生的现金流量净额 |
| 加权平均 ROE | **半年度、未年化**，非全年 ROE |
| 毛利率 | （营业收入−营业成本）÷营业收入；空缺项由 NeoData 直连 2026H1 同源回填，金融类不适用显示「—」 |
| 资产负债率 | 负债合计 ÷ 资产总计 × 100（%），2026H1 时点值，来自 NeoData 直连；金融类同样有值（高负债为行业特征，如银行约 90%）；来源缺失显示「—」。这是**水平指标，不着色** |
| 披露日期 | 正式半年报披露日 |
| 数据来源 / 数据时点 | 每条记录的来源标注；时点统一为 2026-11-18 |

**怎么用 / 技巧**：

- 默认按**归母净利降序**，一眼看到「上半年谁最赚钱」。
- 在顶部「排序维度」里切换为**营业总收入、加权平均 ROE、营收同比、归母净利同比**，可分别看「收入规模最大」「赚钱效率最高」「增长最快」的公司。
- 点击任意列标题可切换升降序；例如把「归母净利同比」切为降序，再看负增长的公司就切为升序。
- 配合顶部筛选：先选产业链/环节，本表只剩该范围内的公司。

### ② 产业链环节赚钱榜

**看什么**：把公司按「**产业链 → 环节**」聚合后，看每个环节整体的赚钱能力。一行 = 一个「产业链×环节」，不是单家公司。随全局筛选联动。

**主要字段**：

| 字段 | 含义与口径 |
|---|---|
| 产业链 / 环节 | 聚合的维度 |
| 环节公司数 | 参与聚合的公司数量 |
| 环节营收合计 | 环节内公司营业总收入之和 |
| 环节营收同比 | 环节合计较上年同期同比 |
| 环节归母净利合计 | 环节内公司归母净利润之和 |
| 环节净利同比 | 环节合计较上年同期同比 |
| 净利同比均值 | 环节合计口径的净利同比（表头标注「环节合计同比」） |
| 环节平均 ROE | 环节内公司 ROE 的算术平均，**半年度未年化** |
| 环节平均毛利率 | 环节内公司毛利率的算术平均 |
| 平均净利率 | 环节归母净利合计 ÷ 环节营收合计 × 100（**环节合计口径**，非公司净利率的算术平均） |
| 赚钱能力排名 | 同一产业链内，按「环节归母净利合计」降序排名，从 1 起 |
| 代表公司 | 环节内公司简介，仅作展示 |
| 数据来源 / 数据时点 | 来源标注；时点 2026-11-18 |

**怎么用 / 技巧**：

- 这是回答「**这条产业链里哪个环节最赚钱**」的专用榜。默认按「赚钱能力排名」升序，排名 1 的就是该产业链净利润合计最高的环节。
- 在顶部选了产业链后，本表只显示该产业链下的各环节；再选环节则进一步聚焦。
- 可切换排序为「环节归母净利合计、环节营收同比、环节平均 ROE、环节公司数」等维度。
- 注意「环节平均 ROE」是公司 ROE 的算术平均，仍是半年度未年化口径，不要和板块⑥的行业 TTM ROE 直接比。

### ③ 双增公司榜

**看什么**：找出「营业总收入同比增长 **且** 归母净利润同比增长」的公司，共 **95 家**。

**入榜硬条件**：`营收同比 > 0` **并且** `归母净利同比 > 0`，两者必须同时为正；任一为空都不入选。

**主要字段**：

| 字段 | 含义与口径 |
|---|---|
| 股票代码 / 股票简称 | 基本信息 |
| 所属产业链 / 所属环节 / 申万一级行业 | 分类标签 |
| 营业总收入 / 营收同比 | 入榜条件：营收同比 > 0 |
| 归母净利润 / 归母净利同比 | 入榜条件：净利同比 > 0 |
| 加权平均 ROE | 半年度未年化 |
| 净利率 | 归母净利 ÷ 营业总收入 × 100，页面实时派生，缺失显示「—」，水平指标不着色 |
| **双增强度** | 综合排序分 = 营收同比 + 归母净利同比（两项均为正）。数值越大代表「双升」越猛 |
| 披露日期 / 数据来源 / 数据时点 | 常规字段 |

**怎么用 / 技巧**：

- 默认按**双增强度降序**，排在最前的是「营收和净利一起涨得最多」的公司。
- 切换到「营收同比」或「归母净利同比」排序，可分别找「收入增长最快」或「利润增长最快」的双增公司。
- 结合顶部产业链/环节筛选，可看「某条产业链里哪些公司是双增的」。

### ④ 产业链内公司对比

**看什么**：在同一产业链/环节里横向比较公司，共 **46 家**。最大特色是**勾选 2～4 家公司高亮并排比较**。

**怎么用勾选对比**：

1. 先在顶部选定产业链/环节，让本表聚焦到同一环节。
2. 在表格左侧勾选想比较的公司（**最多 4 家**，超过会提示）。
3. 被勾选的公司会高亮，页面会显示「已选择 N 家公司（最多 4 家）」并列出所勾选公司，方便并排对照营收、净利、ROE、毛利率、环节内排名及行情快照。
4. 取消勾选即可移出对比。

**主要字段**：

| 字段 | 含义与口径 |
|---|---|
| 股票代码 / 简称 / 所属产业链 / 所属环节 | 基本信息与联动字段 |
| 营业总收入 / 营收同比 / 归母净利润 / 归母净利同比 / 加权平均 ROE / 毛利率 | 财务指标，口径同板块① |
| 净利率 | 归母净利 ÷ 营业总收入 × 100，页面实时派生，缺失显示「—」，水平指标不着色 |
| 环节内营收排名 | 同一「产业链+环节」内按营业总收入降序的名次 |
| 环节内净利排名 | 同一「产业链+环节」内按归母净利润降序的名次（默认排序维度） |
| 最新价 / 涨跌幅 | **行情快照**：某一交易日的最新价与当日涨跌幅，正红负绿；对应「行情日期」 |
| 主力净流入（当日 / 5 日 / 20 日） | 对应交易日的当日、近 5 日、近 20 日主力资金净流入，单元格以上标标注周期；属历史快照 |
| 行情日期 | 上述价格/涨跌幅/资金流对应的交易日，与「数据时点 2026-11-18」（研究整理日）不是一回事 |
| 技术指标数值 | 原始数值集（MACD、KDJ、RSI、均线 MA、布林 BOLL 等）以 JSON 存储；缺项为 `null`，不填 0 |
| 技术面摘要 | 客观文字摘要（如「超卖反弹初期」），并标注来源（工具返回/计算值）；**不含买卖建议** |
| 数据来源 / 数据时点 | 来源标注；时点 2026-11-18 |

**两条重要提示**：

- **行情不是实时的**：最新价、涨跌幅、主力净流入都是某一历史交易日的快照，且带有「行情日期」，请勿当作实时行情使用。
- **无归属龙头**：个别仅有完整财务/行情、但未纳入本次产业链梳理的公司（如贵州茅台）其「所属产业链/所属环节」为空。它们**只在「全部产业链 + 全部环节」视图下显示**；一旦选中具体产业链或环节就会被过滤掉，这是预期行为，不是缺数据。表格附近也有相应提示文字。

### ⑤ 业绩预告 / 待披露观察区

**主要字段**：

| 字段 | 含义与口径 |

| 披露状态 | 已披露正式半年报 / 已发业绩预告 / 待披露未预告 |

| 预告净利同比下限 / 上限 | 预告同比区间，正红负绿 |
| 预约披露日期 | 交易所预约披露日 |

| 是否已入正式榜 | `true`=已披露并迁入板块①，前端会显示「已转正入榜」标记 |
| 备注 | 观察说明；历史预告快照、约值、未获取的信息都在这里标注 |

## 5. 联动筛选玩法

筛选的核心链路是：**产业链 → 环节 → 板块类型 / 排序维度 / 关键词**。切换任一条件，六个板块一起刷新。下面给三个典型场景。

### 场景一：看「AI 算力」产业链里「存储」环节谁最赚钱

1. 在顶部「产业链」下拉框选择 `AI算力`（或包含存储的产业链名称）。
2. 「环节」下拉框会自动列出该产业链下的环节，选择 `存储`。
3. 此时：
   - **板块②** 只剩「存储」环节这一行，直接读出环节净利合计、平均 ROE、赚钱能力排名；
   - **板块①** 只剩 AI算力→存储范围内的正式半年报公司，按归母净利降序看龙头；
   - **板块④** 只剩同环节公司，可勾选 2～4 家并排比较财务与行情快照；
   - **板块⑥** 中层级为「产业链/行业」的相关行随之过滤，而「宏观指标」卡片仍保留作背景。
4. 在板块④勾选几家公司，对照环节内净利排名、ROE 和主力净流入，得出结论。

### 场景二：找「营收和净利一起高增长」且属于某行业的公司

1. 先到**板块③双增公司榜**，默认按「双增强度降序」，记下头部公司。
2. 在顶部「排序维度」切换为「归母净利同比」或「营收同比」，看单项增长冠军。
3. 用「板块类型」或「关键词搜索」输入行业名（如「电子」）进一步聚焦。
4. 对感兴趣的公司，回到**板块①**查看其扣非净利、经营现金流等完整字段，判断增长质量。

### 场景三：回看某公司在半年报正式披露前的预告

1. 到**板块⑤**，用关键词搜索输入公司简称或代码。
2. 观察其「披露状态」「预告类型」「预告净利同比区间」以及「观察统计时点」。
3. 若该记录带「已转正入榜」标记，说明它后来已正式披露并迁入板块①——可到板块①查看正式数据。
4. 注意预告快照的统计时点是 2026-07-15（或 `*ST萃华` 的 2026-08-31），不要误当作当前状态。

> 想恢复全貌时，点击顶部「**重置筛选**」即可清空所有条件、回到默认视图和默认排序。

## 6. 数据说明

### 6.1 统一口径（非常重要）

| 项目 | 口径 |
|---|---|
| 报告期 | **2026H1 半年度报告，累计口径（2026-01-01 ~ 2026-06-30）**，非单季、非年化 |
| 营收 | **营业总收入**（含其他业务收入），不是窄口径的「营业收入」 |
| 净利 | **归母净利润**（归属于上市公司股东的净利润），不是含少数股东损益的「净利润」 |
| 扣非净利 | 扣除非经常性损益后的归母净利润 |
| 公司 ROE（板块①③④） | **加权平均净资产收益率，半年度未年化** |
| 行业 ROE（板块⑥） | **TTM 滚动 12 个月**口径，逐行以「ROE 口径」列标注；禁止与公司级半年度 ROE 直接比较 |
| 同比基准 | 2026H1 对比 **2025H1**；正红负绿 |
| 金额单位 | 存储为「元」的纯数字；展示层可格式化为亿元 |
| 数据时点 | `asOf` = **2026-11-18**，为研究整理日；统计期为 2026H1，二者不同 |

### 6.2 数据来源

数据来自公开渠道，逐条带来源标注。来源包括：

- **金融数据检索**：NeoData 金融搜索、WeStock Data 等工具返回；
- **官方机构**：国家统计局、中国人民银行、海关总署、中国证监会、沪深交易所等。

> 说明：数据采集时部分数据源尚未获得直连授权，因此实际是通过**带来源标注的检索链路**整理入库；每条记录的来源都如实标注，估算/计算值会在备注中注明，不冒充公告原文。

### 6.3 空值「待填」规则

- 未采集到的真实值一律写「**待填**」，**不填 0、不编造任何财务数字**——因为「金额为 0」和「数据缺失」是两回事。
- 页面上「待填」显示为「**—/待填**」。
- 排序时「待填」会**沉到底部**，不会被当作 0 或零增长参与比较。
- 例如：31 个申万一级行业本次只取到 17 个，其余留「待填」，不代表这些行业零增长。

### 6.4 涨红跌绿

遵循 A 股习惯：

- **红色**：正增长 / 上涨（如营收同比 +20%、涨跌幅 +3%）；
- **绿色**：负增长 / 下跌（如净利同比 −15%、涨跌幅 −2%）；
- **灰色**：0 或空值。

该规则作用于所有同比、涨跌幅等字段，不反向着色。整体页面仍保持蓝色主色调，涨红跌绿只影响数值文字颜色。

### 6.5 数据时点速查

| 概念 | 值 | 含义 |
|---|---|---|
| 统计期 | 2026H1（1–6 月） | 财报覆盖的时间段 |
| 数据时点 `asOf` | 2026-11-18 | 研究整理日 |
| 历史预告快照 `statDate` | 2026-07-15（预告截止日）；`*ST萃华` 为 2026-08-31 | 观察快照的实际统计时点 |
| 行情日期 `quoteDate` | 板块④各记录对应交易日 | 行情快照的交易日，与上面两个都不同 |

## 7. 导出与离线使用

### 7.1 导出数据

页面提供两种导出入口，**导出的都是「当前筛选 + 当前排序后」的可见结果**，不是整张原始表：

1. **每个板块右上角「导出当前结果」按钮**：只导出该板块当前显示的行。
2. **顶部「导出 CSV 备份（当前板块）」按钮**：同样导出当前板块的结果。
3. **顶部「导出全部数据 CSV」按钮**：一次性导出全部六张表的数据到一个 CSV 文件，按「板块名 → 中文表头 → 数据行」分段排列、段间空行，导出的是当前内存中的全部数据（在线模式下即为在线数据）。

导出格式为 **CSV 文件**，特点：

- 使用 **UTF-8 BOM** 编码，用 Microsoft Excel 直接打开**中文不乱码**；
- 表头使用中文列名（如「股票代码」「营业总收入」「加权平均ROE」）；
- 字段中含逗号、引号或换行时会按标准规则转义，避免串列；
- 文件名按板块命名（如 `h1_2026_market.csv`）。

> 小技巧：想导出「某产业链里双增公司的对比表」，就先设好产业链筛选、在目标板块排好序，再点该板块的「导出当前结果」，拿到的就是屏幕上看到的那份数据。

### 7.2 在线 / 离线双数据源

工具采用「双数据源」设计，保证可用性：

- **内置离线静态快照（兜底）**：页面内嵌了六张表的静态数据。即使完全断网、没有资料库权限，也能打开并查看全部功能。
- **资料库 SDK 在线按需查询**：六张数据表通过各自的 `databaseId` 关联资料库；页面打开时若检测到在线资料库可用，会按需拉取在线数据替换快照。

切换逻辑：

- 在线查询成功 → 徽标显示「实时资料库」；
- 在线查询失败（网络、权限、未配置、返回异常等）→ 自动回退内置快照，徽标显示「离线静态快照模式」，并在免责声明旁提示「当前为离线快照，数据可能非最新」；
- 六张表各自独立判断，可能出现「混合模式（部分实时 / 部分快照）」。

无需手动切换；重新打开或刷新页面会再次尝试连接在线资料库。也可以点顶部「**从在线数据表刷新**」按钮主动重新拉取六张表——在线模式下会刷新为最新数据；若当前是离线快照模式（SDK 不可用），点击会弹出提示，不会静默失败。

顶部筛选栏下方的**同步状态条**会实时显示当前处于哪种状态（「● 已连接在线数据表（实时）」/「● 部分在线数据表 / 部分快照」/「● 内置快照数据（可同步在线数据表）」），与右上角模式徽标并存。

## 8. 常见问题 FAQ

**Q1：页面顶部徽标显示「离线静态快照模式」，是不是出错了？**
不是。这表示在线资料库当前不可用，工具已自动切换到内置离线快照，数据仍可正常查看和导出，只是可能不是最新。想恢复在线，重新打开或刷新页面即可再次尝试连接。

**Q2：为什么板块⑤里看不到「待披露未预告」的公司？**
因为 2026H1 披露已在 8 月 31 日收官，本板块是「历史观察快照 + 转正归档」视图，不存在当前的「待披露未预告」活样本，这是正常现象。板块内保留了一条真实历史快照（`*ST萃华`，观察时点 2026-08-31）供回看。

**Q3：「已转正入榜」是什么意思？为什么它的预告类型有时是空的？**
「已转正入榜」指该公司当时发过预告（历史快照），后来已正式披露半年报并迁入板块①。若原始来源当时只给了预告上限、没给预告类型/下限/同比，则这些字段留空，遵循「不编造」原则，历史预告值见备注。

**Q4：公司 ROE 和行业 ROE 数值差很多，能直接比大小吗？**
不能。公司 ROE（板块①③④）是**加权平均、半年度未年化**口径；行业 ROE（板块⑥）多为 **TTM 滚动 12 个月**口径，两者尺子不同。板块⑥每行的「ROE 口径」列和对照说明都会标明，请勿混排比较。

**Q5：为什么有些公司在板块④里选了产业链/环节后就不见了？**
少数未纳入本次产业链梳理的公司（如贵州茅台）产业链/环节字段为空，它们只在「全部产业链 + 全部环节」视图显示；选中具体产业链或环节后被过滤是预期行为，不是缺数据。

**Q6：最新价、涨跌幅、主力净流入是实时的吗？**
不是。它们是某一交易日的历史行情快照，带有「行情日期」，与「数据时点 2026-11-18」不同。本工具不提供实时行情、K 线图或预警订阅。

**Q7：导出的 CSV 用 Excel 打开中文乱码怎么办？**
正常情况下不会乱码——导出文件带 UTF-8 BOM。若仍乱码，请在 Excel 中「数据 → 自文本/CSV」导入并选择 UTF-8 编码，或换用较新版本 Excel / WPS。

**Q8：「双增强度」是怎么算出来的？**
双增强度 = 营收同比 + 归母净利同比，仅对「营收同比 > 0 且归母净利同比 > 0」的公司计算，数值越大表示「双升」越强，是板块③的默认排序依据。

**Q9：为什么有些数值显示「—/待填」？**
表示该数据未采集到。工具不会用 0 代替缺失；排序时这些值会沉到底部，不参与数值比较。

**Q10：「待填」和 0 有什么区别？**
「待填」= 没有数据；0 = 确有数据且数值为零。两者语义不同，工具严格区分。
