## 呀呀法语：修复发音 le 被读成字母（用户报"le没法发音读成2个字母"）

- 根因：前端 `speak()` 用浏览器 SpeechSynthesis，系统缺法语 voice 时拿英语引擎硬读法语，`le`→字母 L/E。**非法语错误，是 TTS 引擎问题**。
- 方案：朗读改用 edge-tts 神经语音（`fr-FR-DeniseNeural`），与 ASR 同构——8010 语音服务加 `/tts`（edge_tts.Communicate.stream 收 mp3 + 按 text+voice 内存缓存）、主后端 8000 加 `/api/tts?text=` 代理（音频流 audio/mpeg）、前端 `speak()` 改为 fetch mp3 → `new Audio(URL.createObjectURL)` 播放，失败 `fallbackSpeak()` 回退浏览器 TTS（尽量选 fr voice）。
- 验证：主后端合成用户句 `Très bien ! Vous le voulez chaud ou froid ?` → 200/audio-mpeg/23184 bytes(1.5s)，缓存命中 0s，空文本 400。慢速回听清楚识别 "Vous le voulez" 证明 le 读成单词/lə/；全速 tiny 把 le 听成 ne 是 tiny 连读识别局限非发音问题。
- 收尾：README 补发音章节+API 表+验收、`.venv-asr` 安装命令加 edge-tts。提交 `768e776`。双服务重启后 TTS 就绪。
- **经验**：edge-tts 的 Python API 用 `async for chunk in Communicate(text,voice).stream()` 取 `chunk['type']=='audio'` 的 data 拼 mp3，无需落盘；国内可访问微软服务、免费。浏览器 TTS 读小语种功能词不可靠，语言学习产品应上神经语音 TTS。
