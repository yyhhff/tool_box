## 需求分析

- **目标**：创建服务管理工具，支持启动、重启、关闭项目中的 Web 服务（xhs_crawler、annual_report_reader）
- **改动点**（引用项目地图 `docs/project_content.md`）：

  - 更新 `docs/project_content.md` 工具索引
  - 更新 `docs/data_content.md` 数据登记
- **涉及数据**（引用数据地图 `docs/data_content.md`）：
  - 新增缓存文件 `data/cache/service_manager/services.json`（记录服务状态）

## 方案（已确认）

> 开发前先在会话中向用户提交方案，经用户确认后填写此节再动手。

- **实现思路**：
  - 使用 Python + Flask 提供 Web 管理界面（端口 5002）
  - 通过 `subprocess.Popen` 启动服务进程
  - 使用 `psutil` 检测运行中的服务
  - 服务状态持久化到 `data/cache/service_manager/services.json`
- **改动点清单**：
  - 新建 `tools/service_manager/` 目录
  - 实现 `server.py`（Web 界面）
  - 实现 `service_manager.py`（核心逻辑）
  - 新增 `data/cache/service_manager/` 目录
  - 更新 `docs/project_content.md` 工具索引
  - 更新 `docs/data_content.md` 数据登记
- **风险与限制**：
  - Windows 下通过进程名检测可能不够精确，需处理 `python.exe` 主进程
  - 进程关闭时需确保完全终止，避免僵尸进程
  - 同一服务不能重复启动（加锁机制）
