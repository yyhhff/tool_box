## 原始需求

## 需求分析

- **目标**：①词卡主词与例句的**单个单词**可点击 → 学该单词发音；②**连读教学**进卡：整句/短语连读示范 + 联诵/连音规则讲解 + 连读位置智能提示。
- **现状对照**：规则库已有联诵 ph_final_03 / 连音 ph_final_04（TASK-0027 因跨词无法匹配单 token 而置空 patterns，仅小册子可达）；TTS 整句朗读天然带连读。本任务把"逐词点击 + 连读教学"接到对话词卡流里。
- **改动点**（引用项目地图 `docs/project_content.md`）：
  - `tools/french-learner/frontend/app.js`（token 化渲染 + 连读卡 openLinkingCard）
  - `tools/french-learner/frontend/styles.css`（虚线词/hover、连读卡样式）
  - `tools/french-learner/frontend/index.html`（js v14→v15、css v13→v14）
- **涉及数据**（引用数据地图 `docs/data_content.md`）：
  - 无数据文件/数据库改动；复用规则 JSON 与既有 4 端点

## 方案（已确认）

- **实现思路**：
  1. 词卡主词按空格拆 token，例句拆词（保留标点展示、data-word 用清理后词形），每个单词虚线下划线可点 → 复用 `openPronCardForWord`
  2. 例句尾「🔗 连读」入口；短语卡（含空格主词）加「🔗 连读教学」入口
  3. 连读卡（复用规则浮层，自包含）：🔊 整条连读示范 + 逐词 chips（点击学单词）+ 启发式检测连读位置（前词尾 s/t/d/x/z/n/p/f + 后词元音/h 开头 → 联诵；r/l 结尾 → 连音）高亮 + 联诵/连音规则速览卡（title+讲解+例词）
  4. 检测口径从宽不判错（嘘音 h、数字例外允许漏报/误报，仅提示）；阅读页逐词点击维持 P2 裁决不做
- **改动点清单**：见上
- **风险与限制**：启发式有误差（提示性非断言）；例句省文符按词内保留处理；点击功能词（un/le 等）可能落"未收录"兜底卡（仍有 TTS 可听）
- **用户确认日期**：2026-11-19
