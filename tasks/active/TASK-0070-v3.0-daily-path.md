## 方案（已确认）

- **实现思路**（草案）：
  1. **今日三件事**：后端 `GET /api/today` 聚合生成今日任务清单——① 复习到期词（due 数量，0 时温和显示"今天没有到期词"）；② 读 1 篇 i+1 推荐（recommend 现成）；③ 对话 1 场景 ≥5 轮（复用 chat 历史轮次）。完成判定复用既有事件（review 提交 / reading_logs / chat 轮次），不重复造记录。
  2. **XP 记账**：复习 2xp/卡、阅读 15xp/篇、对话 3xp/轮（封顶 30xp/日防刷）、跟读 5xp/次（挂 v3.2 已有 evaluate 事件）；`xp_events` 表（user/date/source/amount）；等级曲线 = 每 100xp 一级的前缓后陡阶梯，纯函数可单测。
  3. **连续天数深化**：TASK-0060 已有 streak，本版只把"断签不惩罚"固化为产品规则并在今日页显性表达（不归零、只断链）。
  4. **呀呀 IP 陪伴第一期**：今日页呀呀形象随等级/streak 变状态（CSS 绘制 3-4 态：初见/熟悉/默契/老友），零素材依赖。
  5. **挂接点最小化**：DONE 时挂接 xp 不改 chat/review/reading 各自车道模块——在各模块完成事件处后置调用 `gamify.award()`（一行挂接，隔离在 gamify.py 内部 try/except 不阻塞主流程）。
- **改动点清单**：见需求分析；worktree `feature/v3.0-today` 隔离开发。
- **风险与限制**：xp 挂接点触旧模块（chat/review/reading）属跨边界改动，须看板备注并在合并门全量回归；XP 封顶防"睡前狂刷"；今日任务"≥5 轮"对新手可能偏重，A1 用户降为 ≥3 轮。
